GeoNusa Studio

Platform Sosial Media & Publikasi WebGIS Sendiri

Publikasikan data menjadi peta interaktif lalu bagikan ke komunitas

Bagikan peta anda ke publik dengan mudah

GeoNusa Studio adalah platform pemetaan untuk siapa saja yang ingin mengolah dan membagikan data spasial, mulai dari mahasiswa, peneliti, hingga praktisi GIS. Geonusa membantu pengguna menampilkan data yang tersimpan di komputer menjadi peta interaktif yang dapat dibagikan secara online.

Langsung dari Browser

Buka dan tampilkan data spasial tanpa perlu memasang software tambahan.

Informasi Data

Lihat informasi setiap objek pada peta melalui atribut data yang tersedia.

Bagikan Peta

Bagikan tautan peta untuk keperluan tugas, penelitian, laporan, atau portofolio.

Jelajahi Peta Lain

Temukan peta yang dibagikan pengguna lain dan lihat berbagai informasi spasial di dalamnya.

Spesifikasi
Sosial Media Peta
Format Input
ZIP (.shp, .dbf, .shx, .prj)
Tipe Geometri
Polygon, Polyline, & Point
Sistem Koordinat
WGS84 (EPSG:4326) & UTM
Customize Simbologi sendiri dengan format .sld
Unggah file sld langsung dari Qgis
Interaktivitas
Popup dinamis & pembacaan atribut

Workflow

Langkah Publikasi Peta

1
Unggah File Shapefile

Pilih file arsip .shp.zip dari komputer Anda. File langsung di-parse secara lokal di browser.

2
Atur Simbol & Atribut

Preview peta. Tentukan tema warna, ketebalan outline, judul layer, serta konfigurasi field atribut untuk popup.

3
Publikasikan & Bagikan

Hasil webgis dapat diakses langsung oleh dosen, tim kerja, atau publik di perangkat apa pun.
